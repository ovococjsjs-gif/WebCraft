# WebCraft

Блочная игра-песочница в браузере в духе **Minecraft 1.12**: процедурный мир с биомами и
постройками, выживание, творчество, три измерения, игра с друзьями по сети и переносимые
сохранения. Работает без интернета. Это самостоятельный проект, а не копия Minecraft:
1.12 служит ориентиром по правилам и ощущениям.

**Версия 0.12.0.** Что нового: [docs/progress-012.md](docs/progress-012.md) (прошлые
выпуски: [0.11](docs/progress-011.md), [0.10](docs/progress-010.md)).

## Как запустить

| Способ                                 | Что делать                                                                                                                  |
| -------------------------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| **Windows**                            | Распакуй `WebCraft-0.12.0-windows.zip` и дважды щёлкни `WebCraft.exe`. Игра откроется в своём окне.                         |
| **Любой компьютер, один HTML**         | Открой `releases/webcraft-0.12.0.html` в Chrome, Edge или другом современном браузере. Всё нужное уже внутри файла.         |
| **Сервер для друзей** (нужен Node 20+) | `node webcraft-server-0.12.0.mjs`, затем открой `http://localhost:25565`. Подробно в [MULTIPLAYER.md](docs/MULTIPLAYER.md). |

HTML лучше открывать в отдельной вкладке. Во встроенном предпросмотре браузер может
запретить сохранение и захват мыши. Тогда игра покажет «Временный мир» и предложит
экспорт в файл `*.webcraft.json`: сохрани мир, прежде чем закрыть такую вкладку.

На главном экране есть переключатель **«Компьютер / Телефон»**. В режиме телефона
появляются сенсорные кнопки: плавающий джойстик, обзор перетаскиванием, удержание —
ломать, касание — ставить.

## Режимы

- **Выживание.** Добывай ресурсы, крафти, следи за здоровьем и голодом. Ночью выходят
  враждебные существа.
- **Творчество.** Все блоки и предметы во вкладках с поиском, полёт двойным прыжком,
  мгновенное ломание, без урона, голода и сердец.
- **Лаборатория.** Тестовые возможности вместе с механиками выживания. Этот режим
  получают старые импортированные миры, чтобы не потерять прежние возможности.

## Управление

| Действие                         | Клавиши                              |
| -------------------------------- | ------------------------------------ |
| Движение, прыжок                 | WASD, Пробел                         |
| Бег, осторожный шаг              | Ctrl, Shift                          |
| Ломать / атаковать               | ЛКМ (удерживать, чтобы добывать)     |
| Использовать / поставить         | ПКМ                                  |
| Взять блок (творчество)          | СКМ                                  |
| Инвентарь и крафт                | E или F                              |
| Хотбар / выбросить               | 1–9, колесо / Q, Ctrl+Q — всю стопку |
| Полёт / палитра                  | G / P (творчество и лаборатория)     |
| Вид от третьего лица             | F5                                   |
| Скрыть интерфейс / снимок экрана | F1 / F2                              |
| Чат (сетевая игра)               | T или Enter                          |
| Пауза / диагностика              | Esc / F3                             |
| Сохранить сейчас                 | Ctrl+S                               |

В инвентаре: ЛКМ берёт стопку, ПКМ — половину, **Shift-клик** переносит между
инвентарём, хотбаром, сундуком и печью, 1–9 кладут предмет в нужную ячейку хотбара.
Книга рецептов слева показывает ингредиенты, а клик по рецепту раскладывает их в сетке.

## Маршрут выживания

1. **Дерево.** Бей бревно рукой → доски (из любого дерева) → палки и верстак. Верстак
   открывает сетку 3×3.
2. **Камень.** Деревянная кирка → булыжник → каменные инструменты и печь. Уголь
   встречается у поверхности, железо — глубже.
3. **Печь.** Руда и еда кладутся во вход, уголь или доски — в топливо. Shift-клик делает
   это за тебя и забирает готовое вместе с опытом. Жареное мясо сытнее сырого.
4. **Ночь.** Кровать (три шерсти и три доски) пропускает ночь и переносит точку
   возрождения. Броня, щит и меч помогают против зомби, скелетов, пауков и криперов.
5. **Ферма.** Семена выпадают из травы. Мотыга, грядка, пшеница → хлеб. Морковь, картофель,
   свёкла, тыква и арбуз растут так же. Костная мука ускоряет рост и выращивает саженцы
   всех пород.
6. **Деревня.** Компас на экране отмечает домиком деревни в радиусе 512 блоков, их крыши
   видны с горизонта. Правый клик по жителю открывает торговлю за изумруды. Удочка ловит
   рыбу: первый клик — заброс, второй — подсечка, когда поплавок нырнёт.
7. **Глубина.** Алмазы лежат ниже всех руд, добываются железной киркой. Алмазная кирка
   добывает обсидиан.
8. **Нижний мир.** Кремень выпадает из гравия. Огниво зажигает обсидиановую рамку
   портала. Над лавовыми морями парят гасты: отбивай их огненные шары ударом. В
   крепостях живут ифриты и скелеты-иссушители, повсюду прыгают магмовые кубы. Стержни
   ифрита дают порошок для зельеварения и ока Края. Слизь добывается из болотных
   слизней.
9. **Зелья.** Три стекла дают три бутылки. Бутылку наполняют водой, а в варочной стойке
   к ней добавляют адский нарост и другие ингредиенты.
10. **Край.** Око Края летит к крепости. Заполни рамы портала, разрушь лечащие кристаллы
    и победи дракона. Победа сохраняется.

## Графика

- «**Дальние земли**» — упрощённый рельеф до 2048 блоков за пределами обычной
  прорисовки, с настоящими текстурами и плавной градацией: клетки 1, 2, 4, 8 и 16 блоков.
  Строится в фоне и почти не нагружает видеокарту. На слабом устройстве выбери 256 или 512.
- «**Лёгкие шейдеры**» — вода с отражением неба и бликами, свечение тумана к солнцу.
  Стоят почти ничего; выключаются одной галочкой.

## Сетевая игра

По старинке: хозяин запускает `WebCraft.exe` или сервер, друзья подключаются по его IP и
порту (по умолчанию **25565**). Работает в локальной сети, через **Radmin VPN** и
**Hamachi**. Общий мир, видимые игроки и чат. Всё подробно:
[docs/MULTIPLAYER.md](docs/MULTIPLAYER.md).

## Миры и сохранения

- Миры хранятся в браузере (IndexedDB) с атомарной записью и резервной копией
  предыдущей версии. Автосохранение идёт каждые 15 секунд и после изменения блоков.
- «Мои миры» → «Экспорт мира» сохраняет мир в файл `*.webcraft.json`. Импорт создаёт
  отдельный мир.
- **Формат записи 6, чтение форматов 1–6.** Миры из версий 0.2–0.9 открываются и
  переносятся автоматически. Формат 6 не читается старыми сборками, поэтому перед
  переходом на новую версию сделай экспорт важного мира.
- **Новые миры создаёт генератор 5.** Старые миры генераторов 1–4 остаются прежними до
  блока: их ландшафт заморожен контрольными отпечатками в тестах.

Спецификация сохранений: [docs/specs/saves.md](docs/specs/saves.md).

## Известные ограничения

- Пока нет табличек, лодок, картин, рамок, цветочных горшков, лиан, какао, спрутов,
  поводка, седла, бирки и железного голема.
- Производительность проверялась в программном WebGL, а не на настоящей видеокарте.
  Сенсорное управление проверено в эмуляции телефона. Firefox и Safari не
  сертифицированы.

## Разработка

Node.js **20.19+** и npm. Зависимости закреплены в `package-lock.json`.

```bash
npm ci
npx playwright install --with-deps chromium   # один раз
npm run dev                                   # http://localhost:5173
```

| Команда                  | Что делает                                                         |
| ------------------------ | ------------------------------------------------------------------ |
| `npm run check`          | Prettier, TypeScript, ESLint, Vitest и сборка                      |
| `npm run standalone`     | автономный `releases/webcraft-<версия>.html` и его manifest        |
| `npm run build:server`   | сервер одним файлом `releases/webcraft-server-<версия>.mjs`        |
| `npm run build:exe`      | `WebCraft.exe` для Windows в `releases-exe/` (после `standalone`)  |
| `npm run server`         | сервер сетевой игры из исходников                                  |
| `npm run test:browser`   | собрать автономный HTML и прогнать Playwright                      |
| `npm run verify:release` | версии, SHA-256, неизменность прежних выпусков, нет dev API и сети |
| `npm run release:check`  | полный последовательный gate выпуска: всё перечисленное            |

Быстрые ссылки в dev-сборке: `/?preset=flat&radius=2&spawns=off` — плоская лаборатория,
`/?preset=overworld&seed=642018` — обычный мир, `?mode=survival|creative|lab` — режим
нового мира. Отладочный `window.__VOXEL_LAB__` есть только в dev-сборке.

Устройство: `packages/core` — симуляция и генерация мира, `content` — блоки и предметы,
`renderer` — Three.js, `storage` — сохранения, `ui` — интерфейс, `network` — протокол
Worker и сети; `apps/browser` — игра, `apps/server` — сервер сетевой игры и WebCraft.exe.

Прежние автономные выпуски `releases/voxel-lab-0.1.0.html` … `0.9.0.html` сохранены без
изменений. Их SHA-256 закреплены в `fixtures/releases-sha256.json`, и упаковщик
отказывается их перезаписывать.
