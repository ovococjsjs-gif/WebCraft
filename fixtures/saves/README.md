# Настоящие исторические сохранения

Эти шесть файлов экспортированы через интерфейс `releases/voxel-lab-0.2.0.html` — `0.7.0.html` с помощью Chromium. Это не сериализация, полученная новым кодеком. Источник и SHA-256 обеих сторон указаны в `provenance.json`.

| Релиз | Preset    | Формат | Генератор |
| ----- | --------- | ------ | --------- |
| 0.2   | flat      | 1      | 1         |
| 0.3   | flat      | 2      | 1         |
| 0.4   | flat      | 4      | 1         |
| 0.5   | flat      | 4      | 1         |
| 0.6   | overworld | 4      | 2         |
| 0.7   | flat      | 5      | 3         |

0.1 не имел этой системы экспорта. **Ни один из приложенных релизов не экспортировал формат 3.** Его контракт проверяется синтетическим тестом в `review-regressions.test.ts` и прежними unit-тестами, отдельно от этих golden-файлов.

Не форматируйте и не перезаписывайте фикстуры при изменении схемы. Тест должен открыть старый файл, проверить его исходную сумму, мигрировать, сохранить исходный номер генератора и снова проверить полученный конверт. Искажение payload без обновления суммы должно отвергаться.
