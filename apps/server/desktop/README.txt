WebCraft {version} для Windows
==============================

ЗАПУСК
  Дважды щёлкни WebCraft.exe. Игра откроется в отдельном окне.
  Закроешь окно игры, и WebCraft сохранит всё и выключится.
  Интернет не нужен.

  Первый запуск:
  * Windows может показать «Windows защитила ваш компьютер»: у файла нет цифровой
    подписи. Нажми «Подробнее», затем «Выполнить в любом случае».
  * Брандмауэр спросит, разрешить ли WebCraft доступ к сети. Нажми «Разрешить»,
    если хочешь играть с друзьями. Для одиночной игры доступ не нужен.

  Рядом с окном игры открывается чёрное окно: это сервер для игры по сети.
  Не закрывай его, пока играешь. Там же написаны адреса для друзей.

  Чтобы окно было без адресной строки, нужен Microsoft Edge (он есть в Windows
  10/11) или Google Chrome. Если их нет, игра откроется в обычном браузере.

ИГРА С ДРУЗЬЯМИ (Radmin VPN или Hamachi)
  1. Все включают Radmin VPN или Hamachi и заходят в одну сеть.
  2. Хозяин запускает WebCraft.exe. В игре «Сетевая игра» показывает адрес
     этого компьютера для друзей, например 26.12.34.56, порт 25565.
  3. Хозяин сам заходит в сетевой мир кнопкой «Войти →» на главном экране.
  4. Друзья могут:
     * открыть в браузере http://26.12.34.56:25565 и нажать «Войти →»;
     * или запустить свой WebCraft.exe и в «Сетевой игре» ввести IP и порт.

  Сетевой мир отдельный от одиночных миров и хранится у хозяина.

ГДЕ ХРАНЯТСЯ ДАННЫЕ
  %APPDATA%\WebCraft\browser       одиночные миры и настройки
  %APPDATA%\WebCraft\server-world  сетевой мир и игроки
  Мир можно сохранить в файл: «Мои миры» -> «Экспорт мира».

ДЛЯ ОПЫТНЫХ
  WebCraft.exe --help                        все параметры
  WebCraft.exe --port 25570                  другой порт
  WebCraft.exe --mode creative --seed abc    настройки нового сетевого мира
  WebCraft.exe --no-window                   только сервер, без окна
