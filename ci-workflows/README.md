# Workflow-файлы GitHub Actions (ждут переноса)

Здесь лежат `check.yml` и `release.yml` из исходного архива проекта. В `.github/workflows/`
я их положить не смог: приложение Arena, через которое идёт работа с репозиторием, не имеет
права `workflows`, и GitHub отклоняет такой push.

**Как включить CI:** в веб-интерфейсе GitHub откройте файл, нажмите «Edit», в поле имени файла
замените путь на `.github/workflows/check.yml` (и так же для `release.yml`) и сделайте коммит.
После этого папку `ci-workflows/` можно удалить.
