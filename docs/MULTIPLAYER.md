# Сетевая игра WebCraft

Игра по старинке: один человек запускает сервер у себя на компьютере, остальные
подключаются по его IP и порту. Это работает в локальной сети, через **Radmin VPN** или
**Hamachi**. Аккаунты и облако не нужны.

## WebCraft.exe (Windows)

Самый простой способ — `WebCraft.exe`. Это один файл, в котором уже есть Node, сервер и игра.

- Двойной щелчок открывает игру в отдельном окне: Edge или Chrome в режиме приложения,
  без адресной строки.
- Одновременно запускается сервер для друзей на порту 25565. Окно «Сетевая игра» показывает
  адрес этого компьютера.
- Когда закрываешь окно игры, WebCraft сохраняет всё и выключается.
- Данные лежат в `%APPDATA%\WebCraft`: папка `browser` — одиночные миры, `server-world` —
  сетевой мир, `server.log` — журнал.

Собрать exe:

```sh
npm run standalone && npm run build:exe   # releases-exe/WebCraft-<версия>-windows.zip
```

## Хозяину: как открыть мир

1. Установи [Node.js](https://nodejs.org) версии 20 или новее.
2. Возьми файл `releases/webcraft-server-<версия>.mjs`. В этот один файл встроены и сервер,
   и сама игра.
3. Положи файл в отдельную папку и запусти его:

   ```sh
   node webcraft-server-0.12.0.mjs
   ```

   Порт по умолчанию **25565**. Мир сохраняется рядом, в папке `webcraft-world/`.

4. Включи Radmin VPN или Hamachi и зайди с друзьями в одну сеть.
5. Сервер сам печатает адреса, которые можно дать друзьям. Адрес Radmin начинается с `26.`,
   адрес Hamachi — с `25.`.
6. Сам играй в браузере по адресу `http://localhost:25565`.

Ctrl+C сохраняет мир и выключает сервер. Кроме того, мир сохраняется каждые 30 секунд.

### Параметры

| Параметр             | Что делает                                                 |
| -------------------- | ---------------------------------------------------------- |
| `--port <n>`         | порт (по умолчанию 25565)                                  |
| `--world <папка>`    | папка мира (по умолчанию `./webcraft-world`)               |
| `--name <текст>`     | название нового мира                                       |
| `--seed <текст>`     | сид нового мира                                            |
| `--preset <вариант>` | `overworld`, `large-biomes`, `amplified`, `valley`, `flat` |
| `--mode <режим>`     | `survival` или `creative`                                  |
| `--max-players <n>`  | предел игроков (по умолчанию 8)                            |
| `--motd <текст>`     | приветствие в чате при входе                               |
| `--game <файл>`      | отдавать свой HTML-файл игры вместо встроенного            |

Сид, вариант и режим задаются при первом запуске. Потом они хранятся в
`webcraft-world/world.json`.

## Друзьям: как подключиться

Есть два способа.

- **Проще всего:** открыть в браузере адрес `http://IP:порт`, который дал хозяин. На главном
  экране появится зелёная плашка сервера с кнопкой **«Войти →»**.
- **Из своей копии игры:** «Сетевая игра» → ввести имя, IP и порт → **«Подключиться»**.

Имя должно быть от 2 до 16 символов. По нему сервер запоминает, где игрок стоял и что у него
в инвентаре.

> Страницу, открытую по **https**, браузер к серверу не пустит: ws:// оттуда запрещён.
> Поэтому играй по `http://IP:порт` или из скачанного HTML-файла.

В игре:

- **T** или **Enter** открывает чат, **Esc** его закрывает. На телефоне для чата есть
  отдельная кнопка.
- Над каждым игроком висит табличка с именем. Счётчик в правом верхнем углу показывает,
  сколько человек сейчас в игре.
- «Пауза → Отключиться от сервера» возвращает в главное меню. Твой одиночный мир остаётся
  нетронутым: пока ты в сети, игра в него ничего не пишет.

## Как это устроено (v1, «общий мир»)

- Мир у всех строится из одного сида. По сети передаются только **изменения блоков**, а
  сервер хранит их полный журнал.
- Новый игрок получает этот журнал при входе. Правки в ещё не загруженных чанках
  применяются, когда чанк загрузится.
- Если двое меняют один и тот же блок, остаётся последняя правка.
- Положение, поворот, предмет в руке, взмахи, приседание и полёт каждого игрока рассылаются
  10 раз в секунду. У себя клиент их сглаживает.
- Раз в 20 секунд и при отключении клиент сохраняет игрока на сервере: позицию, инвентарь,
  здоровье и голод.
- Протокол — JSON поверх WebSocket по адресу `/ws`. Типы сообщений описаны в
  `packages/network/src/multiplayer.ts`.
- `GET /status` отдаёт JSON с названием, режимом, версией и списком игроков.
- Сервер ограничивает частоту правок и сообщений чата, проверяет каждое сообщение и
  отключает клиентов, которые перестали читать данные.

### Ограничения v1

- **Мобы, выпавшие предметы, сундуки, печи и рост посевов у каждого игрока свои.** Общими
  по сети становятся только сами блоки.
- Свои (загруженные) скины другим игрокам не видны: вместо них показывается встроенный скин.
- Видно только тех, кто в том же измерении. Урона друг другу (PvP) нет.
- Шифрования нет. Играй только с теми, кому доверяешь: Radmin и Hamachi сами шифруют
  трафик внутри своей сети.

Для v2 нужна «многопользовательская» симуляция, которая целиком работает на сервере и
считает мобов, контейнеры и бой.

## Для разработчика

```sh
npm run server -- --port 25599 --world /tmp/wc-world   # сервер из исходников (tsx)
npm run standalone && npm run build:server             # releases/webcraft-server-<версия>.mjs
```

Юнит-тесты сети лежат в `tests/unit/multiplayer.test.ts`.
