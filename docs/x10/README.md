# «×10»: как улучшаем WebCraft

Это рабочая папка большого улучшения игры. Идея такая: перечислить **каждый элемент** игры (код и
геймплей), для каждого решить, что значит «в десять раз лучше», и сделать. Сам список лежит в
[INVENTORY.md](INVENTORY.md), он обновляется по мере работы: у каждой строки есть статус.

## Что значит «в 10 раз лучше»

Не всё улучшается одинаково, поэтому у каждого элемента одна из трёх целей:

| Вид цели     | Как проверяем                                                                             | Пример                               |
| ------------ | ----------------------------------------------------------------------------------------- | ------------------------------------ |
| **Набор**    | считаем штуки командой `npm run catalog`: было N, стало не меньше 10·N или паритет с 1.12 | зачарования 7 → 30                   |
| **Скорость** | замеряем `npm run bench` до и после                                                       | генерация мира, меширование          |
| **Качество** | скриншоты до/после в одинаковых условиях, юнит-тесты на поведение, чек-лист в строке      | небо, постобработка, поведение мобов |

Там, где элемент уже близок к эталону (Minecraft 1.12) и улучшать его ×10 нечем, в таблице стоит
**«держим»** и причина. Это тоже честный результат, а не пропуск.

## Правила работы

1. **Сохранения не ломаем.** Формат записи остаётся 6, миры прежних версий открываются. Всё, что
   меняет ландшафт, уходит в отдельный генератор 6, а генератор 5 остаётся как был.
2. **Каждое улучшение идёт с тестами.** Логика проверяется юнит-тестами в `tests/unit`, визуальные
   вещи смотрим на скриншотах.
3. **`npm run check` остаётся зелёным** (Prettier, TypeScript, ESLint, Vitest, сборка).
4. Ассеты, как и раньше, **рисуются кодом**: внешних картинок и звуков нет.

## Инструменты

| Команда                                | Что делает                                                                                   |
| -------------------------------------- | -------------------------------------------------------------------------------------------- |
| `npm run catalog`                      | считает блоки, предметы, рецепты, мобов, биомы, зачарования, эффекты                         |
| `npm run bench`                        | время генерации чанка (холодный старт, p50/p95/max)                                          |
| `npm run dev` + `window.__VOXEL_LAB__` | dev-сборка с отладочным API: `teleport`, `fly`, `camera`, `mob`, `time`, `weather`, `grant`… |

Для скриншотов достаточно Playwright из проекта (`npx playwright install chromium`): открыть
`/?preset=overworld&seed=642018&radius=3&mode=creative&spawns=off`, дождаться
`window.__VOXEL_LAB__.getInfo().ready`, нажать `#play`, сделать `page.screenshot()`. В программном
WebGL (SwiftShader) кадр идёт медленно, поэтому после каждой телепортации стоит подождать секунды
три, пока догрузятся чанки.
