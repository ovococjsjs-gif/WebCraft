# Инвентарь элементов WebCraft и план «×10»

Состояние на сборку **0.12.0**. Числа взяты из кода командой `npm run catalog` и из замеров
`npm run bench`, а не из памяти. Как читать таблицы и что такое «×10», написано в
[README.md](README.md). Статусы: ⬜ запланировано · 🔨 в работе · ✅ сделано · ➖ держим.
