# Итерация 008 — исправления по результатам ревью

**Сборка:** 0.8.0 · **Дата:** 26 сентября 2026 · **Формат записи:** 6 · **Новый генератор:** 4.

Работа выполнена поверх исходной 0.7.0, без переписывания архитектуры и без замены визуального языка. Исходный ZIP и автономные HTML 0.1–0.7 сохранены. Старые HTML контролируются отдельным SHA-256-манифестом.

## Статус проверки

- Агрегатный `npm run check`: **прошёл** — Prettier, TypeScript, ESLint, **428 тестов в 26 файлах**, production build.
- Node fixture: tick 120, 25 колонок, digest **`a1e33cb7`**, как у исходной версии.
- Реальные экспорты 0.2–0.7: **6 из 6** читаются, мигрируют и повторно проверяются новым кодеком. Формат 3 — отдельно обозначенный синтетический тест.
- Автономный HTML сформирован; встроенные версии, checksum и неизменность семи исторических HTML проверены.
- **Чистый полный gate `CI=1 npm run release:check`: прошёл** в отдельной копии без `node_modules` и `dist`, после нового `npm ci`.
- **Chromium: 41/41**, без пропущенных/нестабильных тестов; 19.5 минуты. Включены file://, opaque iframe без сети, реальные E/F и Ctrl+S, матрица переходов 2/4/5 и GPU lifecycle.
- **GPU-проба:** 20 волн по 24 стрелы и 6 существ; после удаления 3–3 геометрий, в конце 0 объектов сущностей. Это счётчик Three.js в настоящем программном WebGL, не измерение VRAM в МиБ.
- `npm ci`: 164 пакета, аудит 0 уязвимостей. Предупреждения о размере bundle и deprecated ESLint не скрыты; ошибками gate они не являются.
- Первый полный прогон: 39/41. Одна ошибка выявила бесконечно малую остаточную скорость и лишнюю автозапись; вторая — старое ожидание текста ошибки для файла с подменённым checksum. Оба места исправлены, добавлены регрессии; финальный прогон целиком зелёный.

## Дополнительные ошибки, обнаруженные регрессиями

- Предметы в переполненной сетке крафта раньше не попадали в файл. Теперь остатки представляются как дроп в снимке без изменения живого интерфейса.
- Открытая сетка могла потеряться при смене измерения. Перед передачей владения выполняется возврат сетки/курсора.
- Умерший игрок мог снова подобрать свои предметы. Подбор теперь требует живого игрока.
- После отмены невидимого дна игрок умирал ниже −64, что обнажило слишком узкий диапазон координат кодека. Позиции сущностей отделены от высоты хранения блоков.
- Сон устанавливал время 24000, вне допустимого диапазона сохранения. Рассвет нормализован к 0.
- Внешние города Края использовали номер чанка вместо номера клетки структуры; исправлено **только в генераторе 4**. Там появляется соответствующий однократный лут, включая элитры.
- Субнормальная остаточная скорость после остановки непрерывно меняла dirty stamp. Контроллер теперь обнуляет физически незначимый остаток.
- Часы неактивного мира могли отматываться при повторном входе; теперь возвращение наследует актуальные часы игрока.
- Пол модели обычного существа неверно смещался вниз на половину высоты. Render payload трактуется как положение ног.
- Урон окружения дважды списывал износ брони. Двойной вызов устранён; общий путь износа применяется и к луку/огниву при использовании.

## Совместимость и изменения правил

Обычные новые биомные миры — выживание, старые импортированные — лаборатория. В меню создания доступны три режима. Выдача предметов и полёт защищены также на стороне production Worker, а не только скрыты в интерфейсе. Dev API умышленно позволяет строить воспроизводимые тестовые сцены; это не серверная авторизация и не часть standalone.

Генератор 4 не «чинит молча» уже существующие миры 1–3. Это значит, например, что в старом мире генератора 2 по-прежнему нет крепостей Края: для полного нового маршрута нужен новый мир. Старый мир остаётся отдельным и не удаляется.

Некоторые рецепты/числа настроены для собственного прототипа: кристалл из стекла, ока и жемчуга; шанс черепа 25%; обрабатывается фиксированная зона растений. Не заявляется точный Minecraft-баланс или ИИ.

## Расчёт растений

Для политой пшеницы при достаточном свете: 7 стадий × 128 тактов / (20 TPS × 0,12) = **373,3 секунды**, около **6,2 минуты** в среднем. Для сухой при шансе 0,05 — около **14,9 минуты**. Это математическое ожидание, не обещание фиксированного времени каждого растения. Ночь, отсутствие света, уход из активной зоны, остановка симуляции и перегрузка большой очереди увеличивают время. Дальность **рендера** в формулу больше не входит.

## Границы завершённости

Выполнены кодовые исправления и добавлены регрессии по всему перечню, но нельзя честно считать закрытыми аппаратную приёмку производительности R20, пользовательскую оценку R19 и длительный сквозной survival-playtest R10. В контейнере используется программный WebGL. Его FPS не являются результатом для пользовательской видеокарты.

Также не проверены Safari/Firefox, мобильное управление, многопользовательская синхронизация и точная совместимость с Java 1.12.2. Отдельные сложные jobs всё ещё атомарны на уровне колонки/секции: 9 мс — мягкий бюджет очереди, а не гарантия, что любой job уложится в 9 мс на любой машине.
