# Ресурсы и зависимости

Дата: 2026-09-25, сборка 0.2.0.

Все текстуры, значки, шрифты интерфейса и сцена созданы кодом этого проекта. Ресурсы Mojang, оригинальные JAR-файлы, внешние наборы текстур, CDN и сетевые шрифты не используются. Сетевых запросов при запуске нет: это проверено тестами для скачанного HTML.

- **three** — единственная runtime-зависимость; полный текст MIT сохранён в `docs/licenses/three-LICENSE.txt` и в уведомлении внутри сборки.
- **@noble/hashes** — чистая реализация SHA-256 для контрольной суммы файла мира; используется в коде, работает офлайн, без eval и без случайных источников.
- Остальные пакеты — инструменты разработки и тестов; они не входят в поставляемый HTML.
